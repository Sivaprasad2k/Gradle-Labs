# Version 8: External Administration Layer

## Overview
Version 8 introduces the external administration layer for the Java Job Scheduler project. It provides a clean, framework-free Application Service boundary, an HTTP REST API, a CLI Administration Tool, and a Web Administration Console.

---

## Conceptual Architecture

```text
┌─────────────────────────────────────────────────────────┐
│              Web Administration Console                 │
│              (HTML, Vanilla CSS, Vanilla JS)            │
└──────────────────────────┬──────────────────────────────┘
                           │ HTTP REST
┌──────────────────────────▼──────────────────────────────┐
│             CLI Administration Tool                     │
│             (JobSchedulerCli via HttpClient)            │
└──────────────────────────┬──────────────────────────────┘
                           │ HTTP REST
┌──────────────────────────▼──────────────────────────────┐
│                    REST API Layer                       │
│             (JDK HttpServer, /api/v1/*)                 │
└──────────────────────────┬──────────────────────────────┘
                           │ Direct Java Call
┌──────────────────────────▼──────────────────────────────┐
│              Application Service Layer                  │
│   (Job, Execution, Workflow, Scheduler Services)        │
└──────────────────────────┬──────────────────────────────┘
                           │
                 JobScheduler Engine
               ┌───────────┴───────────┐
          JobExecutor             Repositories
        ExecutorService             MongoDB
```

## Key Features

### 1. Application Service Layer (`com.siva.jobscheduler.application`)
- **`JobApplicationService`**: Job creation, listing, retrieval, cancellation.
- **`ExecutionApplicationService`**: Bounded pagination of execution history and attempt inspection.
- **`WorkflowApplicationService`**: DAG dependency relationship visualization.
- **`SchedulerApplicationService`**: Administrative state management (`RUNNING`, `HALTED`, `STOPPED`), metrics summary, thread pool tracking.

### 2. REST API Layer (`com.siva.jobscheduler.api`)
- Built on JDK `com.sun.net.httpserver.HttpServer` on port `8080`.
- Endpoints under `/api/v1/*`:
  - `POST /api/v1/jobs`
  - `GET /api/v1/jobs`
  - `GET /api/v1/jobs/{jobId}`
  - `POST /api/v1/jobs/{jobId}/cancel`
  - `GET /api/v1/executions` (with `page`, `size`, `status`, `jobId` filters)
  - `GET /api/v1/executions/{executionId}`
  - `GET /api/v1/workflows/{jobId}`
  - `GET /api/v1/scheduler`
  - `POST /api/v1/scheduler/halt`
  - `POST /api/v1/scheduler/resume`
  - `POST /api/v1/scheduler/shutdown`
- Serves static Web Console files at `/` and `/console/`.

### 3. CLI Administration Tool (`com.siva.jobscheduler.cli`)
- Command line interface communicating exclusively over REST API endpoints.
- Commands: `status`, `job list`, `job get`, `job cancel`, `execution list`, `execution get`, `workflow get`, `halt`, `resume`, `shutdown`.
- Supports `--json` flag for machine-readable JSON output.

### 4. Web Administration Console (`src/main/resources/web`)
- Dark navy/charcoal engineering console designed with Vanilla HTML/CSS/JavaScript.
- Visual hierarchy with summary cards, active executions table, upcoming executions table, execution history bar graphic, job status donut chart, DAG workflow inspector, and scheduler administration controls.
- Strictly communicates via REST API without direct database access.
